FULL MATRIX CAPTURE (FMC)

FMC acquisition for advanced ultrasonic analysis.

Full Matrix Capture is an ultrasonic data acquisition approach. It records transmit-receive combinations across an array so that the data can be processed into images, including with the Total Focusing Method.

Request a FMC proposal ↗

HOW THE METHOD WORKS

Full Matrix Capture (FMC)

During a typical FMC acquisition cycle, an array element transmits while the available elements receive, and the sequence repeats across the array. The resulting A-scan matrix can be processed using selected imaging algorithms. FMC is the recorded data foundation; the interpreted image and acceptance decision depend on subsequent processing and an approved method.

TECHNICAL CONSIDERATIONS

Limits and complementary methods

FMC is an acquisition method, not a stand-alone flaw classification or acceptance criterion. Data size and capture time can increase substantially, and a useful result depends on setup, processing and qualified interpretation.
